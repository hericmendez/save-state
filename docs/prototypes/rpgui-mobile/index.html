RPGUI Mobile — protótipos isolados

Página de entrada dos protótipos de tipografia, botões, containers e composições mobile. Nada aqui é importado pelas rotas reais da aplicação. Os arquivos são estáticos e servem apenas para avaliação visual e medição de largura antes de qualquer alteração em componentes compartilhados.

A — Tipografia B — Botões C — Containers D — Composições mobile

Como visualizar

A partir da raiz do repositório, execute um servidor estático e abra o endereço indicado. Não há dependências, build ou variáveis de ambiente.

python3 -m http.server 8080 # http://localhost:8080/docs/prototypes/rpgui-mobile/

Abrir via file:// também funciona na maioria dos navegadores, mas um servidor local garante o carregamento das fontes WOFF2 copiadas para assets/fonts/.

Viewports de avaliação

  • 320 px — celular estreito; pior caso de largura útil.
  • 360 px — Android compacto.
  • 390 px — mobile principal.
  • 412 px — Android maior.
  • 768 px — tablet / transição para desktop.
  • 1366 px — regressão desktop.

Princípio orientador

Desktop mantém a experiência RPGUI completa. Mobile mantém a mesma identidade, mas prioriza conteúdo, legibilidade e funcionalidade em vez de ornamentação. A fonte pixelada permanece como assinatura da marca; a leitura cotidiana passa a usar JetBrains Mono.

Limites deste diretório

Protótipos estáticos, sem "use client", sem Zustand, sem componentes de produção e sem novas rotas. Os assets são os mesmos sprites vendorizados, referenciados por caminho relativo e nunca editados.
